Instrucciones
Desarrollar por equipos un programa basado en la propuesta previamente entregada en la primer parte de ésta práctica, considerando además lo siguiente:

Arquitectura del sistema:
Vista.
Controlador.
DTO.
Servicio.
Repositorio.
Modelos (entidades).
Persistencia de datos:
Uso de Hibernate ORM y MySQL.
Pruebas unitarias:
Creación de pruebas unitarias para validar lógica de negocio.

Evaluación:
Revisión de avances en clase.
Presentación del proyecto demostrando su funcionamiento y explicando su construcción.
Prueba de programación: se le harán preguntas técnicas a cada integrante del equipo y así mismo se solicitarán cambios al proyecto durante la presentación del mismo.
Criterios de evaluación:
Por equipo (60%):
Funcionamiento del sistema: el sistema es intuitivo y funcional, libre de errores.
Arquitectura del sistema: se implementa la arquitectura solicitada de manera adecuada.
Persistencia de datos: Integración correcta de Hibernate, creación correcta de entidades y relaciones.
Pruebas unitarias: alto nivel de cobertura, pruebas escritas correctamente.
Desempeño individual (40%):
Se responden correctamente las preguntas.
Se realizan correctamente los cambios solicitados al proyecto durante la presentación.
Participación durante el desarrollo del proyecto, entrega de avances y presentación.
